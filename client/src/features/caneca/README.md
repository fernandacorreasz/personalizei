# Módulo Caneca

Módulo independente do configurador Create & Customize de caneca 330 ml.

- `CanecaPage.tsx`: editor de arte, texto, acabamento, cena, exportações e controles da sessão.
- `components/MugViewport.tsx`: cena Three.js, FBX, rotação manual/automática e gravação da prévia.
- `lib/designTexture.ts`: composição da arte em textura PNG.
- `caneca.css`: regras visuais próprias com prefixo `caneca-`.
- `../../public/assets/caneca/`: FBX, imagens de apoio e marca do módulo.
