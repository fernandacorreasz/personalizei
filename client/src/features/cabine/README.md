# Módulo Cabine de Fotos

Este módulo contém exclusivamente a experiência Create Love: seleção de temas, captura de até três fotos, prévia da tirinha e exportação em PDF.

- `PhotoBoothPage.tsx`: lógica e interface da cabine.
- `cabine.css`: estilos com prefixo `cabine-` para evitar colisões.
- `cabine-print.css`: regras de impressão do formato 56 × 210 mm.
- `../../public/assets/cabine/`: imagens exclusivas da cabine.
