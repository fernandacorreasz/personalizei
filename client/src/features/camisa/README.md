# Módulo Camiseta

Este módulo contém exclusivamente o configurador ATRYÊ de camiseta.

- `CamisetaPage.tsx`: upload, posicionamento, cores, exportação PNG e WhatsApp.
- `components/ShirtCanvas.tsx`: visualização Three.js do modelo GLB.
- `../../public/assets/camisa/`: modelo 3D e padrão visual exclusivos da camiseta.
